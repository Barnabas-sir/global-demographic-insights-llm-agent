# Data and source files

This folder contains the three original input files supplied for the project. They are preserved as received; the analytical workbook contains integrated copies and derived calculations in dedicated worksheets.

| File | Role |
|---|---|
| `raw/Population_Figures_and_Projections.csv` | Primary economy-year demographic observations and projections |
| `raw/Country_Groupings.xlsx` | Economy code, name, region and income-group lookup |
| `raw/Population_Figures_and_Projections_Metadata.xlsx` | Indicator definitions, source notes and aggregation guidance |
