# Uploading this project to GitHub

This package is already arranged in the intended repository structure. You do not need to create folders or upload files one by one.

## Recommended method: GitHub Desktop

1. Download and extract `Global_Demographic_Insights_GitHub_Ready.zip`.
2. Install and open GitHub Desktop, then sign in to GitHub.
3. Choose **File → Clone repository** and select `Barnabas-sir/global-demographic-insights-llm-agent`.
4. In File Explorer, open the extracted folder `global-demographic-insights-llm-agent`.
5. Copy all its contents (including hidden `.gitignore`) into the cloned repository folder. Allow Windows to merge folders and replace files when prompted. Do not copy the outer ZIP file into the repository.
6. Return to GitHub Desktop. Review the changed-file list. It should show the reorganised project files and removals of the old root-level duplicates, if any.
7. Enter the summary `Organise demographic insights project for portfolio publication`, click **Commit to main**, then **Push origin**.
8. Open the repository on GitHub and check that the README preview, workbook, `data`, `docs`, `scripts` and `screenshots` folders are present.

## Important

- Do not delete the GitHub repository itself. Replacing its tracked contents preserves its commit history and repository URL.
- The workbook is the main deliverable. Open it in Microsoft Excel desktop to test the interactive controls.
- The included Python validation script has passed its structural checks. It does not replace manual testing in Excel.
- Review upstream data-provider terms before redistributing the raw source files publicly. The project licence does not relicense third-party data.
